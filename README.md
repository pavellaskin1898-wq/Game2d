# 🏗️ Ангар — конструктор робота (2D)

Простая 2D-игра-конструктор: в ангаре стоит робот, детали которого можно менять.

## Возможности
- **5 слотов деталей**: Голова, Рука правая, Рука левая, Тело, Ноги
- **3 комплекта**: Лёгкий 🟦, Средний 🟨, Тяжёлый 🟥
- **Характеристики каждой детали**: сила 💪, скорость ⚡, грузоподъёмность 📦, вес ⚖️, ХП ❤️
- Итоговые характеристики робота считаются автоматически (скорость — средняя, с штрафом за большой вес)
- Клик по детали на роботе или по слоту справа → выбор нового комплекта

## Запуск
Открыть `index.html` в браузере, либо:
```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

## Файлы
- `index.html` — разметка ангара и панели
- `style.css` — оформление (стены, пол, разметка, карточки)
- `parts.js` — данные деталей (3 комплекта × 5 слотов) и SVG-графика
- `app.js` — логика замены деталей и подсчёта характеристик
